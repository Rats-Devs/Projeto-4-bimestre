o fetch vai buscar a lista de filmes na API e trazer os filmes para o JavaScript, antes de alterar o site

fetch("http://localhost:5160/api/Filme")
O fetch() faz a requisição HTTP para o endereço da API. está pedindo a lista de filmes

fetch() solicita os filmes à API
a API vai no MySQL e devolve os dados em JSON
JavaScript recebe esses dados
depois, os dados são usados para montar o catálogo de filmes

coloquei no final de script.js:

fetch("http://localhost:5160/api/Filme") <- solicita os filmes à API
    .then(resposta => resposta.json()) <- converte os dados para dados que o JavaScript entende
    .then(dados => { <- recebe os dados já convertidos
        console.log(dados); <- exibe a lista
    });

no console do navegador agora aparece o array de teste:
